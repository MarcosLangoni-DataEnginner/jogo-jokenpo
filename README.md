# 🎮 Jogo de Jokenpô

Projeto acadêmico desenvolvido durante o curso de Análise e Desenvolvimento de Sistemas, na disciplina de Desenvolvimento em JavaScript.

## 📌 Sobre o projeto

O Jokenpô é um jogo de Pedra, Papel e Tesoura no qual o usuário compete contra o computador. A aplicação apresenta o resultado de cada rodada e mantém um placar de vitórias, derrotas e empates.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## ✨ Funcionalidades

- Escolha entre pedra, papel e tesoura.
- Jogada aleatória do computador.
- Identificação de vitória, derrota e empate.
- Placar atualizado automaticamente.
- Botão para reiniciar o jogo.
- Efeitos visuais e animação CSS.

## ▶️ Como executar

1. Baixe ou clone este repositório.
2. Mantenha os arquivos `index.html`, `style.css` e `script.js` na mesma pasta.
3. Abra o arquivo `index.html` no navegador.

## 🎯 Objetivo acadêmico

Praticar a estruturação de páginas com HTML, a estilização com CSS e a programação de interações utilizando eventos JavaScript.
